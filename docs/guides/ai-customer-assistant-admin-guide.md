# 当前客户 AI 小助管理员使用说明

## 使用入口

1. 使用 ADMIN 账号登录。
2. 进入“客户管理”，点击某位客户的“查看”。
3. 在客户详情页确认客户编号和数据更新时间，点击“AI 小助”。

## 可以询问

- 当前客户的交易聚合、夜间/跨境/大额风险信号。
- 当前客户的股权、受益所有人和制裁风险摘要。
- AML、KYC、可疑交易监测、存款保险等公开银行知识。
- 当前证据能支持哪些判断、还需要哪些人工复核。

## 不可以询问

- 其他客户或跨客户比较。
- 完整身份证、银行卡、账号、密钥等敏感值。
- 要求 AI 修改风险等级、冻结账户、提交工单或作出审批。
- 非银行金融问题。

## 回答解释

- `EV/KB/LEGAL` 标识代表本次 run 冻结的证据，可用于审计追溯。
- “证据不足”表示当前快照不能支持结论，不代表客户一定无风险。
- “已拒绝/已拦截”表示请求或输出触发安全边界。
- 流连接异常时页面会尝试恢复，最终以刷新后的消息状态为准，不要重复连续提交。

## 责任边界

AI 小助仅提供只读辅助分析，不能代替有权限人员的客户风险分类、可疑交易报告、制裁处置或其他合规决定。
