# ADR-005：暂缓 GraphRAG 与 Late Interaction 进入主链路

- 状态：Accepted
- 日期：2026-08-23
- 决策范围：法规 RAG 在线检索

## 背景

当前仓库法规语料只有少量文档，主要查询是单条法规义务、处置条件和证据引用。现阶段的首要风险是错误引用、过期证据、权限泄露、不可回滚和评测同源偏差，而不是大规模多跳关系推理。

GraphRAG 会引入实体/关系抽取误差、图版本治理、额外存储和查询编排；ColBERT/Late Interaction 会显著增加索引体积与在线计算。若没有可量化瓶颈，强行加入只会增加简历名词而降低系统可信度。

## 决策

主链路继续采用“向量 + 中文词法 + 加权 RRF + Cross-Encoder + 结构化门控”。GraphRAG 和 Late Interaction 保持实验分支，不进入生产主路径。

满足以下条件时才创建 PoC：

1. 语料达到 10,000 个以上有效法规片段，或跨文件关系成为主要召回瓶颈；
2. 经领域专家审批的错误分析中，多跳/关系型问题占失败案例至少 20%；
3. 现有混合检索在调参后 Recall@5 仍低于 90%，且失败不是 ACL、元数据或分块造成；
4. 至少准备 100 条关系/多跳独立金标问题；
5. PoC 相对基线 nDCG@5 提升至少 5 个百分点，且无答案、ACL 和 P95 硬门槛不退化。

## PoC 边界

GraphRAG 图只允许从可信法规语料抽取，节点和边必须携带 source evidenceId、indexVersion、有效期和权限；任何图结论必须回落到原始条文，不允许只引用模型生成的关系摘要。Late Interaction 使用独立索引身份和灰度发布，不与当前 384 维索引混写。

## 后果

短期减少系统复杂度，把投入集中在可验证的正确性、治理与运维能力。未来若真实评测证明存在多跳瓶颈，本 ADR 提供明确、可审计的触发条件，而不是永久排除相关技术。
